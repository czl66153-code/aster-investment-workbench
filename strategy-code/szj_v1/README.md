# SZJ-v1 双退出信号样例

从个人量化研究冻结快照中提取的风险管理逻辑。提供一个可运行的小例子，展示研究代码如何把退出规则转为按历史可见价格计算的信号。

## 规则

- 用入场信号确认当日的连续复权收盘价作为固定参考。
- 后续有效观测较参考价下跌 20% 时，形成退出信号。
- 最高收盘价较参考价上涨达到 40% 后，启动 25% 的收盘回撤退出。
- 两条规则取最早满足者。原有退出信号在相同日期或更早出现时优先。
- 无效或陈旧报价不触发退出。程序返回收盘决策日期，执行应在之后的交易时点另行安排。

## 运行

```bash
python -m pip install -r requirements.txt
python demo.py
python -m unittest discover -s tests -v
```

示例和测试全部使用合成价格，不读取网络、密钥、真实行情、个人账户或雇主文件。函数接口及数据要求见 `szj_overlay.py`。

## 来源与适用范围

逻辑取自 2026-09-23 冻结个人研究快照中 `szj_trade_management.py` 的 `Policy`、`first_overlay`，保留 `loss20_trail40` 的亏损和回撤触发规则、原退出优先和有效观测约束。源码指纹保存在 `provenance.json`。

公开版本仅保留这一双退出分支，移除了策略研究框架、其他候选参数、公司行动映射、全量行情与本地路径。增加了输入校验，用直接价格阈值表达包含等号的边界，避免“涨幅减 1”在 40%/20% 边界处的浮点误差。测试覆盖这两处边界。

这是退出信号组件。入场形态评分、股票池、504 日延期、原策略退出、持仓预算、订单、费用、涨跌停、停牌成交与公司行动仍需独立实现。没有附带可执行组合回测或历史收益结论。

`mark` 应采用连续、口径一致的复权价格。无效观测应携带上一可用报价并设置 `valid=False`，调用方负责公司行动和行情质量处理。信号参考价不能当作实际持仓平均成本。合成样例中的下一交易日只是计划执行时点，不代表一定能成交。
